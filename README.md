# 🚀 Internship Tracker

A simple and efficient web application to track internship applications, manage statuses, and stay organized during the job hunt.

---

## 🔥 Features

- Add, edit, and delete internship entries
- Track application status (Applied, Interview, Rejected, Offer)
- Store company name, role, deadline, and notes
- Clean and user-friendly interface
- Persistent data (if using local storage / database)

---
